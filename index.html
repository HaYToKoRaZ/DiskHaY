GPUI + Rust Performansı

Diskinizi neyin tükettiğini anında görün ve güvenle temizleyin.

DiskHaY, modern GPUI motoru ile saniyede milyonlarca dosyayı analiz eden, treemap tabanlı ultra hızlı disk alanı görselleştirme aracıdır.

İndir (v1.0.5) Mimarisi İncele

Öne Çıkan Özellikler

⚡

Ultra Hızlı MFT & Win32

Windows NTFS Master File Table doğrudan okunur; milyonlarca dosya birkaç saniyede haritalandırılır.

🛡️

Sıfır Hata Silme Koruması

Sistem ve profil dizinleri (`FOLDERID_UserProfiles`) koruma altındadır. Yalnızca taranan ve onaylanan yollar kaldırılabilir.

🎨

GPUI Canvas Treemap

DOM veya WebView yükü olmadan doğrudan GPU hızlandırmalı interaktif mozaik çizimi.

🌐

SSH Uzaktan Tarama

Uzak Linux sunucularına SSH üzerinden bağlanıp ağacı yerel arayüzde gezinin.
