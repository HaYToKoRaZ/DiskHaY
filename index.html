Key Features

Scan millions of files in seconds, visualize usage clearly, and reclaim space with zero risk.

⚡

60+ FPS GPU Interface

Built in Rust with GPUI hardware-accelerated rendering—zero DOM or WebView overhead.

🗺️

Dual Views (Treemap & Details)

Switch instantly between the interactive treemap mosaic and sortable details list from the top bar.

📏

Real Disk Allocation

Measures actual filesystem block usage (st_blocks × 512) rather than superficial file lengths.

🛡️

Safe Staged Cleanup

Nothing is deleted until you review and confirm. Root drives, mounts, and user profiles are protected.

🌍

10 Languages & Themes

Built-in localization with vector flags and persistent Dark/Light theme settings stored in diskhay.ini.

🔄

Auto Update Check & SSH

Non-blocking startup update check plus remote Linux server scanning over SSH in the local UI.

Keyboard & Mouse Controls

Input Action
Click / Hover Select and inspect directory or file details in the side panel
Double Click / Enter Zoom into the selected directory
Backspace / Esc Zoom out to the parent directory
Space / Right Click Mark or unmark a file or folder for deletion
C Open the staged cleanup review modal
R / F5 Rescan the current drive or directory
